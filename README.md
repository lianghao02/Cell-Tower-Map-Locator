# 📱 Cell Phone Locator (手機門號即時定位)

![Version](https://img.shields.io/badge/Version-v3.1-blue)
![License](https://img.shields.io/badge/License-Proprietary-red)

這是一個專為手機門號即時定位設計的專業級 GIS 輔助工具，能快速解析電信查詢回傳的雜亂文字，自動提取關鍵資訊（座標、時間、門號）並進行地圖定位與導航。**v3.1 版本全新升級「最多 5 筆批量軌跡解析 (Batch Parsing)」、「多點時間軸卡片 (Timeline View)」與「清透寶藍扇形自然疊加 (15% Alpha Blending)」。**

---

## ✨ v3.1 核心升級與功能

* **🚀 最多 5 筆批量軌跡解析 (Block Splitting)**：
  * 支援直接貼上包含多筆定位簡訊的長文字，系統自動進行段落切塊分析，獨立擷取每筆門號、請求時間與座標。
  * **5 筆上限防禦**：預設上限 5 筆，若貼上超過 5 筆會自動依時間排序擷取最新 5 筆，並彈出藍色友善提示。
  * **時間自動排序**：根據定位請求時間 (`reqTime`) 由舊到新自動排序，確保移動軌跡動線清晰正確。

* **📅 多點時間軸卡片與對焦 (Timeline View)**：
  * 在 `📡 定位資料` Tab 中，多筆時自動啟動動態時間軸卡片清單（`①`, `②`, `③`...）。
  * 點擊卡片地圖會流暢平移對焦 (`panTo`)，直觀切換各個定位點視角。

* **🎨 寶藍色清透扇形 (15% Alpha 疊加色調加深)**：
  * 扇形統一採用寶藍色 (`#2563eb`) 與 **15% 透明度 (85% 高透光度)**，絕對不蓋地圖，底層路名與門牌清析可辨。
  * **重疊自然加深**：多個基地台發射扇形覆蓋重疊時，由 SVG 自動進行 Alpha 透明度自然加深（2層重疊約 28%，3層重疊約 40%），天然形成信號涵蓋熱區！

* **👣 數字 Badge 標籤與移動軌跡連線**：
  * 多點模式下地圖自動標註帶有號碼 `①`, `②`, `③` 的圓形晶透 Badge Marker。
  * 點與點之間自動繪製移動方向虛線連線（`Polyline Path`），直觀重現嫌疑人或目標的移動軌跡。

* **🗺️ 全畫面滿版背景地圖 (z-0) 與 🎛️ 懸浮折疊控制台 (z-20)**：
  * 控制台採用半透明磨砂玻璃卡片設計，可一鍵向左收合，留給地圖 100% 視覺空間。

* **🔎 高清 22 級地圖放大**：
  * 支援最大 22 級放大，並配合 `maxNativeZoom: 19` 智慧插值防破圖技術。

## 🛠️ 使用教學

1. **貼上資訊**：將電信查詢結果（簡訊或文字檔）貼入上方文字框，或使用「貼上」按鈕。
2. **解析定位**：點擊「⚡ 解析並定位」按鈕，系統將自動提取資訊並展開第一個分頁。
3. **關聯目標位置 (選填)**：
   * 切換至 `🏠 空間對比` 分頁，輸入目標地址點擊 `🔍` 解析定位，或點擊 `🎯 地圖選點` 在地圖上點擊位置。
   * 您可直接在畫面上拖曳橘色 🏠 Pin 到屋頂，左側的「空間關聯分析」面板將即時顯示測距與信號覆蓋狀態。
4. **回報與導航**：
   * 點擊「Google Map」開啟導航。
   * 點擊「複製資訊」取得格式化文字報告。
   * 點擊「LINE」或「Telegram」快速回報。

## 📋 輸出格式說明

本工具會根據**有無目標地址**自動產生對應的格式化報告，方便快速閱讀與分享：

### 格式 A（僅有基地台定位時）：
```text
https://www.google.com/maps?q=23.123456,120.123456
定位門號: 0912345678
定位時間: 2026/07/15 09:30:00
註冊時間: 2026/07/15 09:28:00
定位經緯度: 23.123456, 120.123456 (方位:90)
專用連結: http://... (供點擊開啟專案圖資)
```

### 格式 B（包含目標對比地址時）：
```text
https://www.google.com/maps?q=23.123456,120.123456
定位門號: 0912345678
定位時間: 2026/07/15 09:30:00
註冊時間: 2026/07/15 09:28:00
定位經緯度: 23.123456, 120.123456 (方位:90)

🏠 目標關連位置: 臺南市將軍區南19線3鄰5之1號
📍 目標經緯度: 23.124567, 120.124567
📏 直線距離: 約 185 公尺
🧭 相對方位角: 78° (🎯 位於發射扇形範圍內)
專用連結: http://... (供點擊開啟專案圖資)
```

## 🔧 技術規格

* **前端架構**：原生 HTML5 / CSS3 (Tailwind CSS CDN) / JavaScript (ES6+)。
* **地圖核心**：Leaflet.js (OpenStreetMap)。
* **空間運算**：球面三角學與航向角（Bearing）公式。
* **資安規範**：純前端運行，Local Storage 本地保存，確保公務機敏資料絕不外洩。

---

## ⚠️ 注意事項

* 本工具僅供公務使用，請遵守相關資安與保密協定。
* 座標與地址解析存在少許誤差，實際位置請以現場狀況為準。一鍵傳送至 **LINE** 或 **Telegram** 群組。
  * **歷史紀錄實時同步**：自動儲存最近的查詢紀錄，每當在地圖上拖曳 Pin 或選點微調位置時，空間資訊會實時寫回 LocalStorage，保持歷史追溯一致性。
